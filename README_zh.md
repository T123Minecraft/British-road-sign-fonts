# British Road Sign Fonts

这是由 T123Minecraft 制作的英国道路标识字体资源包，适用于迷上城建模组，不包含 Transport Medium (Greek)、Old Road Sign Font 和 AES Ministry。

这些字体是免费的，下载自：  
https://www.roads.org.uk/fonts/

这些字体受皇家版权（Crown Copyright）保护，并包含根据 **开放政府许可 v1.0（Open Government Licence v1.0）** 授权的公共部门信息。

开放政府许可 v1.0 的完整条款可在此地址查看：  
https://www.nationalarchives.gov.uk/doc/open-government-licence/version/1/open-government-licence.html
